Provider credentials

Codex

An Owner starts headless device login through the pinned Codex App Server. Credentials remain in the server-only Codex home. Available models and their advertised reasoning efforts populate the profile selector.

Ollama Cloud

An Owner supplies an API key over the write-only settings boundary. PointGuide verifies it with the Ollama model catalog and stores only AES-256-GCM ciphertext.

Reviewing agent

An Owner defines versioned primary and reviewer prompts and may use the same model or different providers. Global review enablement exposes the per-question Deep research choice. Requested review fails closed on timeout, invalid output, unsupported claims, or missing configuration.

Operating guide

Local development

PointGuide uses Node 22, Next.js, PostgreSQL, and a commit-bound PointAudio checkout. Fixture authentication is development-only.

Documentation homeIdentity and providersRelease

Setup

npm ci
cp .env.example .env.local
npm run migrate
npm run dev
Never commit secrets. Put database, Cloudflare, Ollama, and encryption values in the approved secret store or local ignored environment file.

Quality gates

npm run typecheck
npm run lint
npm test
npm run build
npm run security:check
git diff --check

Corpus validation

Mount or check out PointAudio, set CORPUS_ROOT and exact CORPUS_COMMIT, then run node scripts/verify-corpus.mjs. The checksum manifest is research/midas-m32/checksums.sha256.

Testing roles

With AUTH_MODE=fixture, the first fixture identity is Owner. Subsequent identities are Pending so approval, Trainer, Admin, and Owner paths can be exercised without weakening production authentication.

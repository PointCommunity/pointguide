Sessions and PDF exports

Every approved account can return to its own evidence-grounded support history, use any remaining follow-ups, and save a print-friendly record.

Conversation contract

  • One session supports one initial question and five follow-up questions.
  • Persisted and model-facing context stays chronological and bounded; the Ask page displays the newest question first.
  • The first completed question becomes the session title. Empty sessions are not shown in history.
  • Evidence is collapsed as one main disclosure, with a nested disclosure for each source.

Search and ownership

Session search is case-insensitive, limited to 200 characters, and matches the current account's session titles, questions, and direct answer text. List, detail, resume, and PDF endpoints always apply the authenticated account ID; a non-owner receives the same not-found response as an absent session.

PDF export

The authenticated export route produces a Letter-sized PDF containing questions, direct answers, safety notes, steps, claim status, evidence titles, locators, and excerpts. Text is bounded and normalized for the embedded print font, sections wrap across pages, and the response is private, uncached, download-only content.

Evidence remains authoritative. A PDF is a snapshot of the answer and evidence available when the session was created. Check PointGuide again before making a time-sensitive or disruptive change.
